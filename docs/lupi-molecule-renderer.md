# Library research molecule

The homepage uses Lupi's existing molecular drawing code to present Library
articles as a spatial specimen. This is a graph visualization: articles are
shown as atoms and recorded article relationships as bonds. Positions, sphere
sizes and colors are display attributes, not molecular coordinates, chemical
elements, chemical bonds, or evidence of scientific agreement.

## Reused source and licensing

`src/lupiInk.js` is the TypeScript 5.1.6 / ES2022 transpilation of
[`packages/ui/src/moleculePage/ink.ts`](https://github.com/alexwelcing/Lupi/blob/146ee91d16d175d4f0cc8ad24f296e48dd430c4d/packages/ui/src/moleculePage/ink.ts)
from `alexwelcing/Lupi`, revision
`146ee91d16d175d4f0cc8ad24f296e48dd430c4d`. The source file SHA-256 is
`5445ec93dce19eaa709636d08bbdd96c4633be53e89fce537ea9778563d69dad`;
the checked-out file matches that revision. Its projection, gradient,
depth-ordering and lighting math are unchanged. The only addition to the
transpiled module is the provenance header. No runtime dependency was added.

Lupi's `NOTICE.md` identifies its extraction from the Lupine monorepo and
licenses first-party code under **AGPL-3.0-or-later**, matching this Library
repository's license. The original first-party content and database licenses
are CC BY-SA 4.0 and ODbL 1.0 respectively. This integration reuses code; it does
not import the historical ecosystem graph or its scientific data. The

The historical reference is Lupi's **Lupine Sphere Grid**, generated by
`tools/generate-sphere-grid-gallery.mjs` and retained under

recorded bonds established the visual direction; Library draws its own
current records instead of replaying that historical dataset.

## Integration

```js
import { createKnowledgeMolecule } from './knowledgeMolecule.js';

const molecule = createKnowledgeMolecule(container, {
  onSelect(articleId, fromKeyboard) { /* update the existing article detail */ },
});
molecule.update({ nodes, links, mode, selected, colorFor });
molecule.reset();
// On unmount:
molecule.destroy();
```

`nodes` and `links` use `buildHomeGraph` / `filterHomeGraph` output. Each link
has string article ids in `source` and `target`; endpoint objects with `id`
are also accepted. Every supplied valid relationship is retained, including
parallel relationship records and their labels/evidence. Invalid endpoints
and self-links cannot become display bonds. Isolated articles remain in the
specimen and in the homepage article list. No proximity-derived bonds are
created.

The model sorts ids deterministically, uses actual relationships for spring
attraction, and uses display-only repulsion and centering. It computes three
spatial coordinates per record. The cache retains at most eight small
geometries; large inputs use 32 rotating repulsion samples per article,
without dropping articles or relationship records. There are 160 bounded
layout iterations and no background simulation. Geometry is independent of
selection, taxonomy colors and radius metrics, so those changes preserve
the user's pose and the articles' positions.

The `equal`, `category` and `status` modes use equal sphere sizes. Connection
size uses full-map `connectionCount`; recency uses only the already-qualified
`date.ms` value, with missing dates retaining a neutral radius. Colors are
supplied by the existing Library taxonomy. The fit radius reserves room for
the maximum metric sphere so changing emphasis does not zoom the object.

The renderer calls Lupi's `InkLayout` and `inkGradientStops`. A Library DOM
painter adds substantial shaded bond strokes, selectable article groups and
selection rings. Article strings enter `textContent` and attributes, not
HTML/SVG string interpolation. Lupi's exported SVG-string helper remains in
the unmodified source copy but is not used for Library article data.

## Interaction and accessibility

- SVG stage: `.knowledge-molecule`, `width="100%"`, `height="100%"`, square
  `viewBox="0 0 200 200"`, preserving aspect ratio. The host controls the
  responsive height; the whole specimen fits at every rotation.
- Article groups: `.knowledge-molecule-atom`, `role="button"`, `tabindex="0"`,
  `aria-label`, `aria-pressed`, full `<title>`, and `data-article-id`.
- Sphere/hit/ring classes: `.knowledge-molecule-sphere`,
  `.knowledge-molecule-hit`, `.knowledge-molecule-ring`.
- Bond classes: `.knowledge-molecule-bond`, `.knowledge-molecule-bond-body`,
  `.knowledge-molecule-bond-light`. Bonds carry source, target and relation
  metadata and preserve relationship descriptions in `<title>`.
- State classes: `.is-selected`, `.is-connected`, `.is-muted`.

Click/tap and Enter/Space select an article; arrow keys rotate the stage and
Home or `reset()` restores the original pose. Desktop drag rotates on two
axes. Touch rotates horizontally while vertical movement remains browser
scroll (`touch-action: pan-y`). A tap retains its original article target
even if the browser retargets pointerup. Drag, cancellation, lost capture and
leaving the stage do not accidentally select; cancelled gestures do not
leave the stage stuck. Depth reordering preserves the focused article.

There is **no automatic spin, inertia loop, timer, global event listener,
network IO, or provider execution**. Normal and reduced-motion users get only
deliberate movement. Destruction releases pointer capture and clears all
handlers. The surrounding Library retains the article list and crawlable
article pages; this renderer does not replace their semantic content.

## Validation scope

`node --test scripts/knowledgeMolecule.test.mjs` covers topology/provenance
retention, deterministic volumetric geometry, metric sizing, missing dates,
fit under multiple camera poses, the original Lupi projection golden sample,
current Library completeness, keyboard/focus behavior, pointer capture,
scroll/cancellation, missed-move protection, unique gradient ids, and cleanup.
At implementation time all 96 current Library articles and 113 relationships
were retained. These local tests do not substitute for desktop/mobile visual
inspection or deployed-site verification.
