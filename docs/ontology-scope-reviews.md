# Reviewed scope for the halide climate target

The historical ontology wording links a barrier underestimate directly to a
conductivity error. The finite barrier and Arrhenius proofs only establish
conditional scalar-rate statements; transport needs additional premises.

The current Library projection qualifies the blocker for `climateTarget:CT2`.
Its review is in `content/ontology/climate-scope-reviews.json`, bound to the
exact source bytes, original field text and source pointer. The raw atlas,
stable identities, links, readiness and original source date remain intact.
The review has its own date and preserves the original wording.

Both production outputs use the shared loader. A changed source or invalid
review stops the build; the review is not silently dropped. The graph inspector
shows the qualified statement, missing premises, review basis and historical
wording. This is a source-specific editorial correction, not automated scientific
fact checking or a new transport model.

The review links to the pinned Rhizo specification and its successful Lean run.
It does not verify the original material-specific estimate, predict conductivity,
validate the proposed correction mechanism or authorize a simulation.

Validation compares the actual checked-in atlas before and after projection,
checks the production output paths and exercises the actual rendering function
with a small DOM test double. These tests do not establish interactive browser
behavior or live deployment. No original source artifact is changed.
