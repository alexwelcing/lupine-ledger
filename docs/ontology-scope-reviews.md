# Reviewed scope for the halide climate target

The historical ontology wording links a barrier underestimate directly to a
conductivity error. The finite barrier and Arrhenius proofs only establish
conditional scalar-rate statements; transport needs additional premises.

The current Library projection qualifies the blocker for `climateTarget:CT2`.
Its review is in `content/ontology/climate-scope-reviews.json`, bound to the
exact source bytes, original field text and source pointer. The raw atlas,
stable identities, links, readiness and original source date remain intact.
The review has its own date and preserves the original wording.

Both production outputs use the shared loader. A changed source or invalid
review stops the build; the review is not silently dropped. The graph inspector
shows the qualified statement, missing premises, review basis and historical
wording. This is a source-specific editorial correction, not automated scientific
fact checking or a new transport model.

The review links to the pinned Rhizo specification and its successful Lean run.
It does not verify the original material-specific estimate, predict conductivity,
validate the proposed correction mechanism or authorize a simulation.

Validation compares the actual checked-in atlas before and after projection,
checks the production output paths and exercises the actual rendering function
with a small DOM test double. These tests do not establish interactive browser
behavior or live deployment. No original source artifact is changed.

## T1 article and catalog scope

The T1 article uses a shared finite profile's energy range, while its reuse and
clean-gate wording can imply a general cross-engine barrier guarantee.
`content/reviews/article-scopes.json` adds a separately dated qualification
above the historical reader body and replaces only the projected subtitle.
It links the checked Lean extension, identifies the initial-state and search-gap
premises, and keeps continuous-path and transport conclusions outside the claim.

The article bytes, original manifest, July recording date and October export
date stay unchanged. The original subtitle remains visible in the review.
Article identity, status, tags, graph links and unrelated entries are preserved.
A changed source hash, catalog wording, target or unreviewed translation stops
the build; it does not silently omit the qualification.

The regular reader, corpus preload, catalog cards, search index and graph use
the same qualified projection. Standalone graph and index builds use the same
loader. Review bytes participate in the presentation version so an unchanged
source-export commit cannot retain the old cached description after a review
update. This is a source-specific editorial correction, not a new inspector,
a fresh corpus export or an explanation of the original campaign's failures.

Production-output tests check that these surfaces agree, the old source clock
survives and the historical body is retained. They do not establish interactive
browser behavior, live deployment, physical validation or improved user decisions.
